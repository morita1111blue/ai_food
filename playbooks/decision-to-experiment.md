# Decision To Experiment

## Purpose

Convert analysis or hesitation into a small reversible experiment.

This is useful when a decision keeps being discussed but does not become action, or when research is producing more complexity instead of a testable next move.

## Template

```text
Decision:
Hypothesis:
Smallest action:
Success signal:
Falsification signal:
Maximum loss / stop condition:
Review date:
What we learn if it works:
What we learn if it fails:
```

## Rules

- Prefer a small test with a review date over a large indefinite commitment.
- Define the condition that would prove the idea wrong before starting.
- Define maximum acceptable loss in money, time, or attention.
- Record what will be learned either way, so failed tests still compound.
- If a decision is repeatedly reopened, check whether the original experiment was ever completed.

## Good use cases

- Trading strategy validation.
- New data collector or dashboard feature.
- Workflow automation.
- Research direction selection.
- Tool adoption, such as a new AI service or local model.
